## 點樣見到 TAG 生效（試玩建議）

1. 用**女兒**開局（已有 投射＋穿透 → 一開始就有「貫穿射線」）
2. 升級揀 **爆裂芯**（爆炸）+ **燃芯**／**毒染** → 擊殺出現燃爆／毒爆大圈
